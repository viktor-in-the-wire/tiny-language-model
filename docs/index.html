CHAPTER I

Words become numbers

Before a model can predict anything, it has to turn language into something it can count.

I.1 — WHAT IT IS

A language model is autocomplete, scaled up.

It reads text, learns which words tend to follow which, then writes by guessing the next word. Again and again.

CHAPTER III

How it learns

It starts out guessing at random. Then it gets a tiny bit less wrong, twenty thousand times in a row.

III.1 — LOSS

Loss is one number for how wrong it is.

Take the probability it gave the right answer, p. Loss = −log(p). Sure and right: near 0. Sure and wrong: it explodes.

CHAPTER IV

What it isn’t

It sounds like it knows things. It doesn’t. Here’s the honest part.

IV.1 — WHY IT’S STILL DUMB

It predicts what’s likely, not what’s true.

Memory: one word.

After “is”, it has no clue if we meant Mars or a whale.

Reading list: 324 words.

This page is longer than its entire education.

Understanding: zero.

It doesn’t know what a moon is. It knows which words hung out together.

CHAPTER V

Breaking it, building it

I study cybersecurity, so my first question was obvious: how do you break it?

V.1 — THE SECURITY ANGLE

If it learns from text, text can attack it.

01 · POISONINGdemo coming next
Change the text, change the model.

Everything my model “knows” came from 324 words. Slip in bad sentences and it learns those too.

02 · FLUENT ≠ TRUSTWORTHY
Sounding right isn’t being right.

03 · PROMPT INJECTION
It can’t tell orders from data.
